# Simulação Termodinâmica do Ciclo Otto

Este repositório contém o código em Python desenvolvido para a modelagem e simulação computacional do Ciclo Otto. O projeto faz parte da Iniciação Científica desenvolvida na Universidade Estadual Paulista (FEIS UNESP).

## Objetivo
Analisar parâmetros de desempenho e eficiência térmica de motores de combustão interna através de simulações numéricas.

## Tecnologias Utilizadas
* Python 3.x
* Bibliotecas: `numpy`, `matplotlib`, `scipy`,  `pandas`

## Como executar
1. Clone este repositório:
   `git clone https://github.com/THEO-CD-04/ICE-FEIS.git`
2. Instale as dependências:
   `pip install -r requirements.txt`
3. Execute o script principal:
   `ICcodeMK9.py`
